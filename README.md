### 香港 BGP 意味着什么

BGP（边界网关协议）多线接入的意思是：**电信、联通、移动等多家运营商的线路在这里做了智能互通**。

对国内用户的实际体感是：

- 不管你家里是电信、联通还是移动宽带，**访问路径都会被自动选到较优的那条**
- 不会出现"电信快、联通慢"这种单线机器的典型尴尬
- 跨网访问的延迟和丢包，通常比单线香港机器更稳定

相比单线机器（比如只有电信优化的线路），**BGP 对多运营商用户更友好**——这也是这台机器值得关注的核心点。

### 30 Mbps 带宽是什么水平

这个数字是这台机器最超出"免费机"预期的部分。做个参照——不少免费机给的是 5 Mbps 档，两者差别不只是数字：

- 5 Mbps ≈ 600 KB/s 左右，传个几百 MB 的镜像要等一会儿
- **30 Mbps ≈ 3.5 MB/s 左右**，日常操作流畅得多

搭配 2 核 2G，能覆盖的场景明显更宽：

- **个人博客 / 静态网站**（Hexo、Hugo、VitePress、WordPress 轻量站）——轻松
- **Bot / 签到脚本 / 消息推送**（Telegram Bot、定时任务、Webhook 接收）——轻松
- **Docker 练手、开发测试环境**——够用
- **轻量 API 服务、Nginx 反向代理**——够用
- **小文件分发、图床**（注意别当主备份）——可跑

### 110 GB 存储怎么用

系统盘 50 GB + 数据盘 60 GB 的分盘方式比很多免费机厚道（不少免费机只给一个很小的系统盘）。建议：

```bash
# 数据盘单独挂载，和系统盘分离，重装系统不丢数据
lsblk                      # 先看清楚数据盘设备名，比如 vdb / sdb
mkfs.ext4 /dev/vdb         # 格式化（确认设备名再执行！）
mkdir -p /data
mount /dev/vdb /data

# 写入 /etc/fstab 实现开机自动挂载（用 UUID 更稳）
blkid /dev/vdb
echo 'UUID=<上一步查到的UUID> /data ext4 defaults 0 2' >> /etc/fstab
mount -a && df -h
```

**网站、数据库、Docker 的数据目录都放 `/data`**，这是用好这台机器的关键习惯。

### ❌ 不适合

- 生产业务主节点

- 数据库核心、唯一数据源
- 高并发、大流量站点（30Mbps 是共享带宽，跑满会互相影响）

原因很直接：**免费机普遍存在超售，性能波动是常态**。任何免费资源都不该承担"挂了就赔钱"的责任。

### ⚠️ 三条铁律

1. **重要数据必须有第二份备份。** 不管用哪家免费机，哪怕它备案证照齐全，**数据只有一份就等于裸奔**。机器没了可以再开一台，数据没了就是真没了。建议 本地 + 对象存储 + Git 仓库，三选二起步。
2. **别把它写进关键链路。** 免费机的可用性不做承诺，DNS、支付、认证这类关键环节别挂上去。
3. **别在同一条船上放两个鸡蛋。** 如果同时用了多家免费机，别让它们互相做备份——它们可能一起挂。
